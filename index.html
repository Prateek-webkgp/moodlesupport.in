Operational Work

Systems I built from scratch

Real problems. Production solutions. Every system below is live and serving 10,000+ institutional users at IIT Patna.

01 / AUTOMATION

Process Automation — Class Communication System

Institutional communication ran on a broken manual process with no audit trail and high failure rate.

Problem Faculty had to manually find course email groups, open Outlook, compose and send — 15 minutes per message. No logging, no accountability.
Approach Rebuilt as a single-trigger automation with pre-mapped course groups, one-click dispatch, and automatic audit logging to a central dashboard.
Result 60+ operational units now communicate instantly. Full audit trail maintained. Zero missed communications since launch.
Before: 15 min manual · After: under 10 seconds · Scale: 10,000+ users
02 / REPORTING TOOL

Centralised Grade Reporting & Faculty Self-Service

Faculty had no central view of grade data — every report was pulled manually from multiple interfaces.

Problem 300+ faculty spending 2–3 hours per week pulling grade data across programs. High support ticket volume from basic data requests.
Approach Designed a role-based reporting tool with multi-program visibility, cohort filters, and direct CSV export — accessible from one interface.
Result Faculty self-serve entirely. Support tickets for grade data dropped to near zero within one semester.
Impact: 300+ faculty · Time saved: 2–3 hrs/week/person · Support tickets: near zero
03 / RECORDS MANAGEMENT

Academic Records Management — Transcript System

End-of-semester transcript generation was a slow, error-prone manual process consuming days of admin time.

Problem Generating one transcript required navigating 10+ screens per student. 15–20 minutes per record. End-of-semester crunch consumed full weeks.
Approach Built a records system with cohort/batch/programme filters, formatted to institutional standards, with bulk export and digital delivery.
Result Entire semester batch generated in minutes. Zero manual exports. Institutional standard formatting guaranteed every time.
Before: 20 min/record · After: under 60 seconds · Errors: zero
04 / INFRASTRUCTURE

Backup & Recovery Pipeline Rebuild

A pre-exam restore failure locked out faculty and students — the trigger for a complete infrastructure rethink.

Problem Manual semester backups with no verification. Storage bloat accumulating unchecked. One failure caused a full pre-exam lockout — high-stakes consequence.
Approach Designed fully automated pipeline: scheduled backups, integrity verification, alert system for failures, automated storage cleanup lifecycle.
Result Zero restore failures since rebuild. Backup time reduced 30%. Storage fully self-managing with no admin intervention required.
Backup time: 30% ↓ · Restore failures: zero · Admin hours: eliminated
05 / ONBOARDING

Zero-Disruption Semester Onboarding — 10,000+ Users

Every semester was a manual scramble — thousands of accounts, enrolments, and configurations under tight pre-semester deadlines.

Problem New participant accounts, enrolments, cohort assignments and role configurations all done manually. Errors meant locked-out students on Day 1.
Approach Designed a repeatable automated process: pre-validation, dry-run staging, bulk provisioning, and rollback procedures for each semester cycle.
Result 100% Day-1 access for three consecutive semesters. Zero reported failures. Process runs with minimal admin oversight.
Scale: 10,000+/semester · Day-1 access: 100% · Failures: zero
06 / IDENTITY & ACCESS

Enterprise SSO — Google & Microsoft Integration

Fragmented authentication across two identity providers was generating a continuous stream of preventable support tickets.

Problem 10,000+ users on separate auth systems. Password resets, login failures, and access issues consuming admin bandwidth every week.
Approach Configured OAuth2-based SSO across both Google Workspace and Microsoft Azure AD, mapped to institutional roles and access tiers.
Result Auth-related support tickets eliminated entirely. Users log in once, access everything. Admin team freed from a recurring category of overhead.
Users: 10,000+ · Auth tickets: eliminated · Providers: Google + Microsoft
